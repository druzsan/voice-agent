# Use of AI tools in the Carrie voice-agent project

AI tools supported the project from initial use-case exploration through implementation and review:

- **Codex with ChatGPT-6 Astra:** Discussion, planning, and reviews of code and architecture. Dialog helped challenge assumptions, compare alternatives, and refine implementation plans.
- **Claude Code with Opus 5.5:** Implementation of the agreed specifications and plans, including application code, prompts, integrations, migrations, and tests, followed by revisions based on review findings.
- **ChatGPT in voice mode:** Quick iteration on customer journeys for delivery delays, charging problems, connected services, and warranty disputes. Spoken role-play explored tone, interruptions, topic changes, and escalation. The results were exported as written specifications and evaluation cases.
- **Legal and privacy assessment:** Discussion of the EU AI Act, AI disclosure, how the assistant should open the dialog, recording and consent, and zero data retention. This included distinguishing provider retention from application storage and identifying questions for legal/privacy validation.
- **Architecture assessment:** Multiple rounds of dialog examined both the working prototype and an Azure scale-up proposal. Topics included speech and model providers, agent tools, conversation state, reliable business actions, human handover, security, privacy, resilience, and capacity.

The workflow connected journey design, planning, implementation, and review in repeated iterations. The human author remains responsible for design decisions and validation; legal assessments and production architecture proposals require specialist review and operational evidence.
